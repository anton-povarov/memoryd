# Understanding is rebuildable

A Memory references one immutable content-addressed Blob, while its Derived Content and Facts can be replaced by a Rebuild using newer extractor or plugin versions. A Rebuild prepares a complete Understanding Run before atomically making it active; failed attempts create only an informative execution log and leave the previous active Run untouched. Explicit user-requested Codex enhancement follows the same rule: it stages a new complete Run containing the regular pipeline result plus Codex enrichment. Repeating an equivalent successful Codex enhancement is permitted after client confirmation. This allows understanding to improve without duplicating or mutating the thing the user originally entrusted to the Vault.
