# Issue tracker: Local Markdown

- Feature: `.scratch/<feature>/`
- Spec: `.scratch/<feature>/spec.md`
- Tickets: `.scratch/<feature>/issues/<NN>-<slug>.md`
- Comments: append under `## Comments`
- Publish: create the appropriate file under `.scratch/<feature>/`
- Fetch: read the referenced path or numbered ticket

For wayfinding, use `map.md`; tickets have `Type:`, `Status:`, and optional `Blocked by:` fields. Claim before working, then resolve with an `## Answer` and add the result to the map.
